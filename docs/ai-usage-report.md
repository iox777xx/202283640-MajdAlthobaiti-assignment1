# AI Usage Report

## 1. AI Tool Used and Use Cases

I used ChatGPT as a supporting tool while working on this project.

I mainly used it when I needed help understanding HTML, CSS, and JavaScript concepts. I also used it to check my code, understand errors, and get suggestions when I was unsure how to implement something.

## 2. Benefits and Challenges

ChatGPT helped me understand coding concepts faster and gave me explanations when I got stuck.

One challenge was that I sometimes needed to change the suggested code to make it work correctly with my own project. I tested the changes in the browser to make sure everything worked as expected.

## 3. Learning Outcomes

This project helped me improve my understanding of how HTML, CSS, and JavaScript work together.

I learned more about website structure, CSS layout, responsive design, adding images, and using JavaScript to create an interactive Dark/Light Mode feature.

## 4. Responsible Use and Modifications

I used AI as a learning and support tool. I reviewed and tested the suggestions instead of using them without checking them.

I made the project content my own by choosing my personal information, projects, skills, website structure, and design. I also tested the website myself and made changes when needed.

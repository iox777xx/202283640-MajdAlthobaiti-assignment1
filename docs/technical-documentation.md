# Technical Documentation

## 1. Project Overview

This project is a personal portfolio website for me as a Software Engineering student at KFUPM.

The website includes a short introduction about me, my projects, my skills, and a contact form.

## 2. Technologies Used

I used:

- HTML
- CSS
- JavaScript

## 3. Files and Folders

The project contains the following main files and folders:

- `index.html` for the website content and structure.
- `css/styles.css` for the design and layout.
- `js/script.js` for the JavaScript feature.
- `assets/images/` for the project images.
- `docs/` for the documentation files.
- `README.md` for general information about the project.

## 4. Website Sections

The website has four main sections:

### About Me

This section gives a short introduction about me and my studies.

### Projects

I added two projects:

- KFUPM Bus Tracker
- NAT Telecom Student Plans

Each project has a short description and an image.

### Skills

This section shows some of the skills I have worked with, such as Java, HTML, CSS, JavaScript, SQL, and OOP.

### Contact

The contact section has fields for the visitor's name, email, and message.

## 5. Responsive Design

I used CSS Flexbox and media queries to make the website work on different screen sizes.

I also tested the website in the browser to make sure the layout looks good when the screen size changes.

## 6. JavaScript Feature

I added a Dark/Light Mode button using JavaScript.

When the button is clicked, the website changes between dark and light mode. The button text also changes depending on the current mode.

## 7. Images

The project images are saved in the `assets/images/` folder.

I used relative paths in the HTML to display the images on the website.

## 8. Testing

I opened the website in the browser and checked the navigation links, project images, contact form, and Dark/Light Mode button.

I also checked that the images appear correctly and that the website layout works on different screen sizes.

## 9. Possible Improvements

I could add more projects in the future and add more interactive features to the website.

I could also connect the contact form to a backend so that messages can actually be received.

# Majd Althobaiti - Portfolio

## About the Project

This is my personal portfolio website as a Software Engineering student at KFUPM.

The website includes information about me, my projects, my skills, and a contact form.

## Projects

The portfolio includes two projects:

- **KFUPM Bus Tracker** - A software project for helping KFUPM students track buses, view schedules, and find bus stations.
- **NAT Telecom Student Plans** - A business project focused on affordable mobile plans for university students.

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Features

- Responsive design for different screen sizes.
- Navigation between the different sections.
- Project images.
- Dark/Light Mode using JavaScript.
- Contact form.
